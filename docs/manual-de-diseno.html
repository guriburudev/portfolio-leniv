01 · Visión General

Manual de Diseño
y Estilo UI

Guía de estilo completa para el Portfolio Fullstack Interactivo. Este documento define los fundamentos visuales, tokens de diseño, componentes y reglas de interacción que garantizan coherencia y calidad profesional en todas las interfaces.

📐
Principios de Diseño
1. Claridad ante todo: Cada elemento tiene un propósito. Sin decoración superflua.
2. Consistencia predecible: Patrones repetibles de espaciado, color y tipografía.
3. Movimiento con intención: Las animaciones comunican estado, no entretienen.
4. Accesibilidad como requisito: Contraste WCAG AA mínimo en todas las combinaciones texto/fondo.

02 · Identidad

Monograma e
Identidad Visual

El logotipo personal se construye como un monograma tipográfico monospaciado, enmarcado en un contenedor con esquinas redondeadas. Transmite precisión técnica y minimalismo funcional.

Concepto del Monograma

Se utiliza la notación </> como símbolo universal de código, combinada con las iniciales del desarrollador en tipografía JetBrains Mono Bold. El monograma se renderiza sobre fondo de acento primario (--accent-primary) con esquinas redondeadas proporcionales al tamaño de la variante.

Reglas de Accesibilidad

♿
Checklist obligatorio:
• Todo elemento interactivo tiene un estado :focus-visible con ring de 3px en --border-focus.
• Las imágenes llevan alt descriptivo. Los íconos decorativos llevan aria-hidden="true".
• El contraste de texto sobre fondo nunca es inferior a 4.5:1 (AA) para cuerpo y 3:1 para texto grande.
• Se respeta prefers-reduced-motion: reduce deshabilitando animaciones GSAP y transiciones CSS no esenciales.
• Los formularios usan <label> vinculado o aria-label en cada input.
• La navegación por teclado (Tab/Shift+Tab) recorre todos los elementos interactivos en orden lógico.
